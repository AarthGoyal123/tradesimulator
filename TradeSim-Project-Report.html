3. Core Features

🖥️ JavaFX Desktop Application (4 Tabs)

📊 Market Tab

  • Live stock table (5 columns: Symbol, Name, Price, Sector)
  • "Refresh Prices" button — simulates ±2% random walk
  • Persists price changes to SQLite database
  • TableView with ObservableList data binding

💹 Trade Tab

  • Stock dropdown (ComboBox) loaded from DB
  • Side: BUY / SELL | Type: MARKET / LIMIT
  • Dynamic UI: Limit price field enables only for LIMIT
  • Validation: qty > 0, cash check for BUY
  • 0.1% transaction fee
  • MARKET orders fill instantly; updates cash + holdings

💼 Portfolio Tab

  • Holdings table: Symbol, Name, Qty, Avg Price, Current, Value, P&L
  • Computed columns: value = qty × current, P&L = qty × (current - avg)
  • Refresh button reloads from database
  • P&L column ready for color coding (green/red)

📜 Orders Tab

  • Order history: ID, Symbol, Side, Type, Qty, Price, Status
  • Shows PENDING, FILLED, CANCELLED
  • Ordered by most recent first (DESC)
  • Refresh button

🌐 Spring Boot REST API (Port 8080)

EndpointMethodDescription
/api/stocksGETAll stocks with current prices
/api/stocks/{symbol}GETSingle stock detail
/api/stocks/{symbol}/priceGETCurrent price only

4. Database Schema (SQLite)

-- Auto-created on first run (Database.init())

CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    username TEXT UNIQUE,
    password TEXT,
    cash REAL DEFAULT 10000
);

CREATE TABLE stocks (
    symbol TEXT PRIMARY KEY,
    name TEXT,
    price REAL,
    sector TEXT
);

CREATE TABLE holdings (
    user_id INTEGER,
    symbol TEXT,
    qty INTEGER,
    avg_price REAL,
    PRIMARY KEY (user_id, symbol)
);

CREATE TABLE orders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER,
    symbol TEXT,
    side TEXT,        -- BUY / SELL
    type TEXT,        -- MARKET / LIMIT
    qty INTEGER,
    price REAL,
    status TEXT DEFAULT 'PENDING'  -- PENDING / FILLED / CANCELLED
);

7. How to Run

Option A: IntelliJ IDEA (Recommended)

  1. File → Open → Select pom.xml
  2. Wait for Maven import (auto-downloads dependencies)
  3. Run TradeSimApp class (green play button)
  4. Launches Spring Boot on port 8080 + JavaFX window
  5. Login: demo / demo123

Option B: Command Line (Maven installed)

cd TradeSim
mvn clean package -DskipTests
java -jar target/TradeSim-1.0.0.jar

Option C: API-Only Mode (No JavaFX)

# Run SpringBootApp class directly in IDE
# Or:
java -jar target/TradeSim-1.0.0.jar --spring.main.web-application-type=servlet

9. Report Talking Points

🏆 For "Advanced Project" Claim

  • Hybrid Architecture: Single codebase runs as both desktop app and REST API server
  • Spring Boot 3: Dependency injection, component lifecycle, REST controllers, actuator health checks
  • JavaFX 23: Modern UI with TableView, data binding, event-driven updates
  • Embedded Database: Zero-config SQLite with schema migration on startup
  • Module System: Proper JPMS configuration for Spring + JavaFX interop

💻 For "Core Java Skills" Claim

  • OOP: Encapsulated models, separation of concerns (UI/DB/Model)
  • Concurrency: JavaFX Platform.runLater, Timeline for price simulation
  • Collections: ObservableList, Stream API for portfolio calculations
  • Exception Handling: Try-with-resources, custom exceptions in REST layer
  • Generics: TableColumn factory method col(title, Function)

👥 For "Team Work" Claim

  • Clean module boundaries: Each person owns one tab method (~30-40 lines)
  • Shared contracts: Models define data shape; Database defines persistence API
  • Integration: All tabs use same Database bean; Spring manages lifecycle
